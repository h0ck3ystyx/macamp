# Screenshot plan — MioAmp 1.0

Apple currently accepts one to ten Mac screenshots at a consistent 16:10 size: 1280×800, 1440×900, 2560×1600, or 2880×1800. Use PNG without transparency. The release set will use 2560×1600.

Capture the actual release build with generated or redistributable audio only:

1. **Your music, your player** — Studio Graphite player, playlist, equalizer, and visualization arranged together while a generated FLAC track plays.
2. **A playlist that stays out of your way** — resized playlist with embedded titles, selection, search, and visible drag placement.
3. **Shape every band** — usable equalizer at 100% scale with a preset selected.
4. **Make it yours** — the same module arrangement in Paper and Terminal skins, with no third-party artwork.
5. **See the sound** — visualization window showing one original preset and its sensitivity control.

Before upload, verify each image is 2560×1600, opaque RGB, free of personal paths/notifications, and accurately reflects build 1.0.0. Screenshots containing the Taylor Swift test files are forbidden because redistribution rights are not established.

Apple reference checked September 29, 2026: https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/
