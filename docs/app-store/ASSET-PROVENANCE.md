# App Store asset provenance

## App icon

- Final repository master: `MacAmp/Resources/MacAmpIcon-master.png`
- Final properties: 1024×1024, opaque sRGB PNG, SHA-256 recorded with each release candidate
- Derivatives: the ten PNGs in `Assets.xcassets/AppIcon.appiconset`, generated by lossless resizing with macOS `sips`
- Creation method: OpenAI image generation, edit mode, using the first generated concept as the only reference image
- Human direction: original charcoal hi-fi player face, amber play symbol, five green level meters; no text, people, trademarks, third-party logos, or named-product imagery
- Visual review: full-bleed square background, central content inside the mask-safe area, legible play and meter silhouette at small sizes

Final edit prompt:

> Edit this MacAmp app icon for current macOS App Store delivery. Preserve the existing charcoal hi-fi player, amber play triangle, and five green spectrum meters, but remove the white canvas and the pre-rounded outer silhouette. Recompose the artwork as a full-bleed opaque square 1024×1024 icon layer with a dark graphite background extending cleanly to every edge, so macOS can apply its own rounded-corner mask. Keep all essential controls safely centered and away from the corners. Simplify tiny textures enough to remain readable at 16 px. No text, letters, trademarks, transparency, border outside the canvas, watermark, or third-party imagery. Output a single polished square icon master.

The icon is original project artwork. Product-name clearance is separate and remains required before submission.

Studio Graphite, Paper, Terminal, and CreatorExample are original repository assets. Their source SVG and manifest files ship in the app. No third-party logo or product artwork is included.
